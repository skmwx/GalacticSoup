# Overview

This is the first block of post-MVP feature - Combat Progression Alpha.

## Fits progression and choices
Introduce real fitting progression. Several weapon families, tank choices, propulsion/range-control choices, ammunition/damage types, perhaps 20–30 modules total. Enough that two viable fits for the same ship behave materially differently.

## Hull progression and choices
Introduce second and third hull. We mainly want to test whether upgrading from, say, frigate → destroyer/cruiser produces the satisfying “I used to fear that encounter; now I crush it” progression.

## Enemy variety expansion
Introduce more enemies, with archetypes rather than just stronger enemies. A fast close-range frigate, slow artillery ship, tanky brawler, missile ship, maybe an electronic-warfare enemy. 

Expand possible loot, add modules that can drop.

## Site progression
A site progression ladder. 10–15 encounters grouped into several difficulty bands. Some should punish inappropriate fits rather than merely requiring higher DPS.
