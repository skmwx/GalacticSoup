# What this is

This is an MVP review done by a human.

# UI

## Overall
Collapse the three headers into one, 3 take too much valuable vertical space.

Game name is not needed (but keep the icon). Player name and the current system stay. "Engine ready over a dedicated worker." is not needed. Settings should become a game menu button without text label, just the icon currently used for settings. Under game menu, there should be current game menu items, and an entry for "settings", which should lead to the settings as they are now.

Sound and alert should be moved to settings.

When a button is disabled for some reason in any view, don't write the reason next to it distorting the UI. Make the reason to appear in the tooltip.

## Overview
When docked, the overview main section has buttons that are duplicates of left hand menu. Remove them.

## Market
Make a switch between sell and buy mode. Show only one set of prices in each, show only items that player has in sell mode.

Make it somehow visible which weapon any given charge is suited for; add an indication for the charges that fit at least one of the weapons player has in their current fit.

Remove full item name from "Buy" button, one icon should be enough. Similar for "inspect" button and for "sell" button.

For modules, make it visible which slot they fit into.

## Hangar
Split it into two columns, hangar and hold, each column lists respective items, there is a button to move all of the item, one of the item or the amount specified in the edit box.

## Fitting
Clicking "Change fit" presents the same information as the initial screen, plus some functionality.

Keep the initial compact screen and move "change fit" functionality to it. Add a "change module" small button to each module, the button shows a popup (or just a drop-down) that shows possible modules.

Make ammo choice a dropdown for weapon line ites.

Add the ship's general info (like shiled and armor and capacitor) on top. 

Keep weapons statistics at the bottom.

## Services
Move everything to main screen.

Repair is a simple operation with a price, just show the "repair armor", "repair hull" and "repair all" button with a price.

Similar with resupply ammunition.

## Departure
Site selection should happen in space, not at departure.

## In Space
Harbor should be one of the destinations, no need for a separate retreat button.

Remove "Coordinates & point navigation" drop down, and make it a right click in the radar view and if it happens to be on an empty space, have "Set course" menu.

Remove "Your ship" from the list of objects present in the sector.

Combine weapons panel and equipment panel (where the shiels booster is)
